# AlgoWen · 算问集

**把零散面经，变成扎实的底气。**

AlgoWen 是一份面向推荐、搜索、广告与大模型算法岗位的面试复习题库，帮助你从原始问法出发，理解知识点、推导过程与工程权衡。

**[打开网站 →](https://dqdallen.github.io/algowen/)**

## 在这里可以做什么

- **浏览 323 道复习题**：按学习主题浏览，搜索考点、模型或原始问法。
- **找到适合自己的内容**：按公司、岗位方向、知识标签、年份、答案状态与学习状态筛选；支持分页浏览。
- **理解问题的来处**：查看来源链接和原始问法，对照参考答案梳理思路。
- **建立自己的复习节奏**：开始练习、收藏题目、记录笔记，标记掌握情况与待复习内容。
- **备份学习进度**：导出或导入学习记录，方便迁移与保存。

## 关于题目与答案

题目来自公开面经与资料的整理。综合题是复习卡，不表示每条关联来源都逐字问过所有子问题；来源中的原始问法以改述形式呈现，并保留出处。

来源是作者自述或汇编，不代表公司认证。收录来源数不是独立面试次数、真实考频或通过率，题库也不是全网穷尽样本。未知的公司、岗位与日期不作推测。

参考答案是另行编写的学习材料，可能包含 AI 辅助内容，并非原作者或招聘方的标准答案；请结合原始资料与自己的理解判断。部分题目仍待补充答案。

## 学习记录与隐私

无需注册。收藏、笔记和掌握状态保存在当前浏览器，不会自动同步到其他设备。清除站点数据、更换浏览器或访问地址后，原有记录可能不可见；建议定期导出备份，迁移时再导入。

希望 AlgoWen 帮你少一些无效搜集，多一些真正理解。
